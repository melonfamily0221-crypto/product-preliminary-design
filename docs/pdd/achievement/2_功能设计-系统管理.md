#### 系统管理

##### 参数设置

###### 功能描述

提供对系统级运行参数、配置项的动态化管理。通过此模块，管理员无需修改代码或重启服务，即可在界面上直接调整如：默认初始密码、验证码开关、系统名称、皮肤样式等全局系统参数。

###### 业务流程

```mermaid
graph TD
    A[管理员登录] --> B{选择操作}
    B -- 新增参数 --> C[定义参数键名及键值]
    B -- 修改参数 --> D[更新参数键值]
    B -- 删除参数 --> E[校验是否为系统内置参数]
    C --> F[保存生效并刷新缓存]
    D --> F
    E -- 是内置参数 --> G[提示无法删除]
    E -- 非内置参数 --> F
    F --> H[系统其它业务模块获取最新参数运行]
```

##### 字典管理

###### 功能描述

提供系统中固定枚举数据（如下拉框选项、状态值、业务类型等）的集中管理。通过“字典类型”与“字典数据”两级结构维护，业务表只需保存字典键值，降低数据冗余，并支持前端组件动态读取渲染。

###### 业务流程

```mermaid
graph TD
    A[管理员登录] --> B{选择操作}
    B -- 新增字典类型 --> C[定义字典标识及名称]
    B -- 配置字典数据 --> D[进入字典类型, 添加键值对]
    B -- 删除字典类型 --> E[校验是否存在关联字典数据]
    C --> F[保存生效并可被前端引用]
    D --> F
    E -- 存在字典数据 --> G[提示无法删除或连带删除]
    E -- 无字典数据 --> F
    F --> H[前端组件重新读取或刷新缓存]
```

##### 岗位管理

###### 功能描述

提供对企业或组织内部岗位信息的统一管理功能。支持岗位的增删改查及数据导出，岗位信息通常与用户资料进行绑定，为系统工作流审批、业务角色划分提供数据支撑。

###### 业务流程

```mermaid
graph TD
    A[管理员登录] --> B{选择操作}
    B -- 新增岗位 --> C[填写岗位编码及名称等信息]
    B -- 修改岗位 --> D[更新岗位基础资料]

    C --> F[保存生效]
    D --> F
    E -- 已分配用户 --> G[提示无法删除]
    E -- 未分配用户 --> F
    F --> H[用户管理模块中分配岗位时可供选择]
```

##### 用户管理

###### 功能描述

提供对系统用户的全面管理功能，包括用户的增删改查、数据导入导出、密码重置、状态启停等，以满足平台权限和用户身份认证的基础需求。

###### 业务流程

```mermaid
graph TD
    A[管理员登录] --> B{选择操作}
    B -- 新增 --> C[填写用户资料]
    B -- 导入 --> D[下载模板并上传数据]
    B -- 修改 --> E[更新用户资料]
    B -- 删除 --> F[确认并删除记录]
    C --> G[保存成功]
    D --> G
    E --> G
    F --> G
```

##### 菜单管理

###### 功能描述

提供对系统左侧导航菜单、页面按钮权限标识的统一配置管理。支持树形层级结构的无限极菜单分类，能够灵活定义页面组件路径、路由地址及控制菜单的显示与隐藏状态。

###### 业务流程

```mermaid
graph TD
    A[管理员登录] --> B{选择操作}
    B -- 新增/修改菜单 --> C[填写菜单基础信息及路由配置]
    B -- 删除菜单 --> D[校验是否包含子菜单]
    C --> E[保存生效]
    D -- 包含子节点 --> F[提示无法删除]
    D -- 无子节点 --> E
    E --> G[角色管理侧同步可被授权]
```

graph TD
